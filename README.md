# Start From JD

> 反向 SOP 简历助手：从你自己开始，而不是从 JD 开始。

大多数人写简历是照抄 JD，结果千篇一律，ATS 也分不出你和别人的差别。
真正稀缺的不是"匹配 JD 的人"，而是**清楚自己能交付什么的人**。

**Start From JD** 反过来：先让你把过往经历倾倒给 AI，它帮你结构化提炼；
再对照目标 JD 生成针对性的单页 A4 简历；
最后给出残酷诚实的诊断，告诉你为什么会被拒、以及怎么改。

## 怎么用

| 步骤 | 你做什么 | AI 做什么 |
|---|---|---|
| **1. 头脑风暴** | 用麦克风口述 / 上传旧简历 / 直接打字，把过往经历倾倒出来 | 去除口水话、结构化整理成"经历文档" |
| **2. 匹配度检查** | 粘贴目标 JD | 输出对比表 + 0–100 匹配分 + 是否值得投 |
| **3. 简历草稿** | 确认后一键生成 | 基于你的真实经历，输出单页 A4 简历，量化成果优先 |
| **4. 诊断** | 看 5 条带危险等级的批评 | 🔴 致命 / 🟠 重要 / 🔵 微瑕，每条带可执行建议 |
| **5. ATS 打磨** | "应用反馈"迭代，或"最终打磨" | 严格 ATS 合规 → 导出 PDF / DOCX / TXT |

## 三条铁律

这个工具的输出能直接用，是因为它强制遵守三条规则：

- **绝不捏造**：AI 严禁编造任何经历、数字、公司、职责 —— 缺失就标红，绝不补全
- **绝不奉承**：诊断步骤强制用 Anthropic Opus 模型，反"价值观回声"硬规则，只说事实
- **单页是硬约束**：内容溢出时优先裁剪低影响项，绝不缩字号或编内容凑数
